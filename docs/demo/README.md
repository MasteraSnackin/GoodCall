# GoodCall demo

The selected demo is **70 seconds**: the original 60-second creator workflow, followed by a matching ten-second chapter about the latest follower features. It follows Maya’s workflow through audience questions, the connected canvas, answer review, follower advice, chat and voice controls, and evidence reports.

The final chapter shows how followers can find advice and save private notes, while Maya sees local activity and answers that need another evidence check. It uses the original screenshot-walkthrough style and the same synthetic British English narrator, Kokoro Emma.

To explore the walkthrough, download the ZIP, extract it and open the HTML file in a browser. The screenshots are embedded, so it works offline. Use the labelled hotspots to look closer, the arrow keys to change screens, and Escape to reset the view. The downloadable HTML is a saved-screen viewer, not a hosted GoodCall app.

These materials use saved screenshots with authored highlights. They are not a recording of live app interactions. Chat and voice controls are shown briefly; the demo does not establish successful live AI generation, microphone or speaker operation, or a Tano or social-account connection. The voiceover is synthetic narration, not audio generated by GoodCall. Follower notes and activity remain local to each browser; the demo does not show cross-device analytics.
