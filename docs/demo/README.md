To explore the walkthrough, download the ZIP, extract it and open the HTML file in a browser. The screenshots are embedded, so it works offline. Use the labelled hotspots to look closer, the arrow keys to change screens, and Escape to reset the view. The downloadable HTML is a saved-screen viewer, not a hosted GoodCall app.

These materials use saved screenshots with authored highlights. They are not a recording of live app interactions. Chat and voice controls are shown briefly; the demo does not establish successful live AI generation, microphone or speaker operation, or a Tano or social-account connection. The voiceover is synthetic narration, not audio generated by GoodCall.
